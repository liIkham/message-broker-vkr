# message-broker-vkr

message-broker-vkr — заготовка Python-проекта для учебной ВКР по брокеру сообщений. В репозитории подготовлены базовые сервисные директории для API-слоя и consumer-слоя, а также отдельная директория для тестов.

Проект ориентирован на Python 3.11 и минимальный набор зависимостей для FastAPI-приложения и интеграции с RabbitMQ через `pika`.
